# מערכת להזמנת רכב משותף

מערכת להזמנת רכב משותף לגמ"ח, קהילה או ארגון: הרשמה ואישור משתמשים ורישיונות, יומן זמינות, בקשות הזמנה ואישור מנהל
(או אישור אוטומטי), מניעת הזמנות כפולות, מיילים ותזכורות, נהלים, ניהול הרכב ומסמכיו. הממשק בעברית, מימין לשמאל,
ומותאם לטלפון ולמחשב.

כל לקוח מקבל אתר משלו, עם מסד נתונים, כתובת, מיתוג ומנהלים משלו. **מרכז ניהול** אחד מנהל את כל האתרים.

## הפעלה על המחשב

דרישות: Node.js 22.13 ומעלה.

- **Windows:** לחיצה כפולה על `start.cmd`
- **Mac/Linux:** `./start.sh`

הסקריפט מתקין, יוצר נתוני דמו ופותח את **https://localhost:3000**. בפעם הראשונה הדפדפן יזהיר על התעודה: בוחרים
"מתקדם" ואז "המשך". כניסה: `admin@example.org` / `Password1`.

## איפה זה רץ

| | |
|---|---|
| **האתרים** | Vercel: כל לקוח בפרויקט משלו, ומסד נתונים ב־Turso. כל push ל־`main` מעדכן את כל האתרים יחד ([docs/vercel.md](docs/vercel.md)) |
| **מרכז הניהול** | פרויקט Vercel נפרד (`APP_MODE=master`): יצירת לקוחות, כניסה לכל אתר כמנהל, מיתוג, השהיה ([docs/master.md](docs/master.md)) |
| **תזכורות ומיילים** | GitHub Actions מפעיל את מרכז הניהול כל 10 דקות, והוא מריץ את המשימות של כל האתרים (`.github/workflows/jobs.yml`) |
